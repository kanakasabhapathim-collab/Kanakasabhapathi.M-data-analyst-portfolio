# Kanakasabhapathi M. — Data Analyst Portfolio

Responsive dark-navy portfolio built with HTML, CSS and JavaScript for GitHub Pages.

## Files
- `index.html` — content, links, projects, certifications and experience
- `styles.css` — layout and responsive styling
- `script.js` — navigation and current year
- `assets/profile.png` — profile photo
- `resume.pdf` — add your current resume PDF here

## Before publishing
1. Replace the generic LinkedIn URL in `index.html` with your actual profile URL.
2. Add your resume PDF in the repository root and name it `resume.pdf`. The resume links open in a new tab.
3. Check the email, phone, project repository, and certificate links.
4. Verify every description and any performance metrics before using them in job applications.

## GitHub Pages
Upload the contents of this folder to the root of a public repository. For a user site, name the repository `YOUR-USERNAME.github.io`, then select **Settings → Pages → Deploy from a branch → main → /(root)**.
